# Social Vibe

Responsive two-page website for a fictional social media marketing agency.

## Files
- `index.html`: homepage
- `services.html`: services page
- `css/style.css`: shared styling, responsive breakpoints, dark mode, reduced-motion support
- `js/script.js`: accessible mobile navigation and current footer year

## Open locally
Keep the folder structure intact and open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository called `social-vibe`.
2. Upload the two HTML files and the `css` and `js` folders to the repository root.
3. Go to Settings → Pages.
4. Select deploy from the `main` branch and `/ (root)`, then save.
5. After publication, copy the website URL for the assignment.

## Four implemented features
1. Responsive mobile, tablet, and desktop layouts.
2. Accessible mobile navigation with `aria-expanded`, plus a skip link.
3. Reduced-motion support via `prefers-reduced-motion`.
4. Dark color scheme via `prefers-color-scheme`.

Validate both HTML files with the W3C Nu HTML Checker before submitting.
